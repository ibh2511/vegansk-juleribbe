# Vegansk juleribbe

Landingsside og salgsløsning for oppskriftsheftet «Vegansk juleribbe med sprø, stekt svor».

- `index.html` – landingssiden
- `takk.html` – siden kunden kommer til etter Vipps
- `last-ned.html` – nedlasting av det personlige, vannmerkede heftet
- `admin.html` – passordbeskyttet statistikk
- `vilkar.html`, `personvern.html` – salgsvilkår og personvern (utkast)
- `backend/` – Google Apps Script som håndterer Vipps, e-post, vannmerke og statistikk

Se [OPPSETT.md](OPPSETT.md) for hvordan alt settes opp.
